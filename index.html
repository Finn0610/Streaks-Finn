Đồng Bộ Đám Mây Với Google Sheets

Lưu tiến trình vĩnh viễn qua Google Apps Script — không bao giờ mất dữ liệu trên Google Sites

Bước 1: Tạo Google Sheet mới → Tiện ích mở rộng → Apps Script → Dán mã này: 
function doGet(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName('StreakFireData') || ss.insertSheet('StreakFireData');
  var raw = sheet.getRange('A1').getValue();
  var output = raw ? String(raw) : JSON.stringify({ empty: true });
  return ContentService.createTextOutput(output).setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName('StreakFireData') || ss.insertSheet('StreakFireData');
  var payload = e.postData && e.postData.contents ? e.postData.contents : '{}';
  sheet.getRange('A1').setValue(payload);
  sheet.getRange('B1').setValue('Đồng bộ lúc: ' + new Date().toLocaleString('vi-VN'));
  return ContentService.createTextOutput(JSON.stringify({ status: 'success' })).setMimeType(ContentService.MimeType.JSON);
}

Sau khi dán mã: Nhấn Triển khai (Deploy) → Tùy chọn triển khai mới (New deployment) → Ứng dụng web (Web app) → Chọn quyền truy cập: Bất kỳ ai (Anyone) → Sao chép URL Web App dán vào ô bên dưới.
